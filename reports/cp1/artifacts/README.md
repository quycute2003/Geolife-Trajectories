# Artifact bàn giao CP01

Các tệp dưới đây là phần tổng hợp từ kết quả đã lưu trong `artifacts/benchmark/`.
Notebook tiếp tục đọc và ghi kết quả thực thi trong thư mục local đó.

| Bước | Tệp bàn giao |
|---|---|
| [B1](b1/) | Audit profile nguồn |
| [B2](b2/) | Ma trận kịch bản tổng hợp và kiểm tra sinh dữ liệu |
| [B3](b3/) | Tổng số theo cấu hình làm sạch và bản xác minh |
| [B4](b4/run_v1/) | Bảng và biểu đồ so sánh detector trên dữ liệu tổng hợp và mô tả dữ liệu thật |
| [B5](b5/roles_v1/) | Tỷ lệ, lý do gán và biểu đồ độ ổn định Home/Office |
| [B6](../benchmark.md) | Quyết định và giới hạn thực nghiệm |

Dữ liệu GPS, bảng tọa độ suy luận theo người dùng và cache phục vụ chạy lại được lưu local.
Kết quả Home/Office mô tả độ ổn định của quy tắc. GeoLife thiếu nhãn độc lập để đo độ chính xác.
